SMART CALCULATOR - RUN INSTRUCTIONS

1. Keep index.html, style.css, and script.js in the same folder.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation, backend, database, or package manager is required.
4. Calculation history is stored in browser localStorage.
5. Clear History removes the locally stored calculation history.

Keyboard shortcuts:
0-9       Number input
.         Decimal
+ - * /   Operators
%         Percentage
Enter/=   Calculate
Backspace Delete last digit
Escape    All Clear
