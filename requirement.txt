PROJECT: E-Commerce UI Application (SauceDemo

BASE_URL: https://www.saucedemo.com/

OBJECTIVE:
Test the user journey of an e-commerce application including login, product selection, cart, and checkout.

ACTORS:
- Customer

FUNCTIONAL_REQUIREMENTS:

FR-001: User should be able to login with valid credentials
INPUT: username, password
EXPECTED_OUTPUT: user navigates to products page

FR-002: User should see list of products after login
EXPECTED_OUTPUT: products displayed

FR-003: User should be able to add product to cart
INPUT: product
EXPECTED_OUTPUT: cart count increases

FR-004: User should be able to view cart
EXPECTED_OUTPUT: selected products displayed

FR-005: User should be able to checkout
INPUT: first_name, last_name, postal_code
EXPECTED_OUTPUT: checkout successful

FR-006: User should logout successfully
EXPECTED_OUTPUT: redirected to login page

NEGATIVE_SCENARIOS:

FR-007: Invalid login
INPUT: wrong credentials
EXPECTED_OUTPUT: error message displayed

NON_FUNCTIONAL_REQUIREMENTS:

NFR-001: Page load < 3 seconds
NFR-002: UI should be responsive
NFR-003: No UI crashes
