SYSTEM_DESIGN: E-Commerce UI Application

ARCHITECTURE:

User → Browser → Web UI → Backend Services

MODULES:

1. Login Module
   - Accept credentials
   - Validate login

2. Product Module
   - Display products
   - Add/remove items

3. Cart Module
   - Show selected items

4. Checkout Module
   - Capture user details
   - Complete purchase

5. Logout Module
   - End session

FLOW:

1. User opens website
2. User logs in
3. User views products
4. User adds item to cart
5. User opens cart
6. User proceeds to checkout
7. User completes order
8. User logs out

PSEUDOCODE:

function login(username, password):
    if valid(username, password):
        navigate_to_products()
    else:
        show_error()

function add_to_cart(product):
    click_add_button(product)

function checkout():
    fill_details()
    confirm_order()
